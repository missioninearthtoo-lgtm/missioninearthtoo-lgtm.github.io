yt-watch

プライバシーポリシー / Privacy Policy

制定日 2026-11-05 ・ 運営: 個人

このアプリについて

yt-watch は、運営者本人が自分のパソコンだけで使う個人用ツールです。運営者自身が登録しているYouTubeチャンネルの一覧と動画の一覧を読み、公開されている字幕を本人のパソコンに保存します。一般の方への提供はしていません。

yt-watch is a personal tool used only by its owner on the owner's own computer. It is not offered to anyone else.

使うデータ

  • 権限は youtube.readonly(YouTubeアカウントの表示)だけです。投稿・削除・変更はしません。
  • 読むのは、登録チャンネルの一覧と、そのチャンネルの動画一覧(タイトル・公開日)です。

The only scope is youtube.readonly. The app reads the owner's subscription list and the upload lists of those channels. It never posts, deletes or changes anything.

保存と共有

読んだデータと認証情報は、運営者本人のパソコンの中にだけ保存します。第三者への提供・販売・広告利用はしません。外部のサーバーにも送りません。

Data and credentials are stored only on the owner's computer. Nothing is shared, sold, used for ads, or sent to any other server.

Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の利用と移転は、限定的使用の要件を含む Google API Services User Data Policy に従います。

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

アクセスの取り消し・お問い合わせ

アクセス権は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。お問い合わせは、Googleの同意画面に表示されるサポートメールまで。

Access can be revoked at any time from your Google Account's third-party apps page. Contact: the support email shown on the Google consent screen.
